# 🍕 Pizza Sales Analysis using SQL

## 📌 Project Overview

This project demonstrates SQL-based data analysis on a Pizza Sales dataset to uncover valuable business insights. The analysis focuses on sales performance, customer ordering patterns, revenue generation, and product popularity using SQL queries.

The objective of this project is to showcase practical SQL skills by solving real-world business problems through data analysis.

---

## 🎯 Business Objectives

- Analyze overall pizza sales performance.
- Calculate total revenue and total orders.
- Identify top-performing pizzas based on sales and revenue.
- Understand customer ordering behavior.
- Analyze sales trends by day, month, category, and size.
- Generate actionable insights for business decision-making.

---

## 📊 Dataset

The project uses a relational Pizza Sales dataset consisting of multiple tables:

- Orders
- Order Details
- Pizzas
- Pizza Types

The dataset contains information about:

- Order Date
- Order Time
- Pizza Name
- Pizza Category
- Pizza Size
- Quantity Sold
- Price

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/chopadepoonam/pizza-sales-analysis-sql.git
```

2. Open MySQL Workbench.

3. Import the Pizza Sales dataset.

4. Execute the SQL script:

```
pizza store sales analysis.sql
```

5. Review the query outputs and insights.
